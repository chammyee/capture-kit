# config.json

`config.example.json`을 복사해 만듭니다. 시작 문구를 쓰면 Claude가 대신 작성합니다.

## 항목

| 항목 | 설명 | 예시 |
|---|---|---|
| `project` | Figma 섹션 이름 | `"호텔 앱 벤치마킹"` |
| `device` | `mobile` (390×848) 또는 `desktop` (1440×900) | `"mobile"` |
| `languages` | 수집할 언어 | `["ko"]`, `["ko", "en"]` |
| `maxShots` | 화면당 최대 스크롤 캡처 수. 넘으면 아래쪽이 잘리고 보고서에 표시됩니다 | `20` |
| `measureFonts` | `true`면 폰트 목록을 `output/fonts.csv`로 저장합니다 | `false` |
| `screens` | 수집할 화면 목록 | 아래 참고 |
| `sites` | 사이트 목록. `name`, `group`, `url`이 필수입니다 | 아래 참고 |

## 화면 지정

| 방법 | 예시 | 쓰는 경우 |
|---|---|---|
| 시작 URL 그대로 | `{ "name": "홈" }` | 홈 화면 |
| 메뉴에서 찾기 | `{ "name": "리스트", "find": ["rooms?", "객실"], "minPrices": 4 }` | 메뉴 이름을 알 때. `minPrices`는 그 화면에 있어야 할 가격 수입니다 |
| 첫 가격 클릭 | `{ "name": "상세", "from": "리스트", "click": "price" }` | 상품 상세 |
| 지정 요소 클릭 | `{ "name": "상세", "from": "리스트", "click": "a:has-text('자세히 보기')" }` | 가격을 눌러도 이동하지 않을 때 |

자동 찾기는 키워드, `전체보기`, 메뉴의 3번째 항목 순서로 시도합니다. 최대 3단계까지 들어가고, 못 찾으면 건너뜁니다.

## 사이트 지정

```json
{
  "name": "예시 호텔",
  "group": "호텔",
  "url": "https://www.example.com/",
  "urls": { "리스트": "https://www.example.com/rooms" }
}
```

| 항목 | 설명 |
|---|---|
| `group` | Figma에서 같은 줄에 놓을 묶음 |
| `urls` | 화면별 URL 직접 지정. 자동 찾기보다 우선합니다 |
| `terms` | `"ok"`면 약관 자동 검사를 건너뜁니다. 사람이 약관을 직접 읽고 문제없다고 판단한 사이트에만 넣으세요 |

## 결과 상태 (`output/report.csv`)

| 상태 | 뜻 | 할 일 |
|---|---|---|
| `done` | 수집 완료 | 없음 |
| `ok` | 약관 검사에서 금지 문구를 찾지 못함 | 없음 |
| `ban` | 약관에 자동 수집 금지로 보이는 문구가 있어 건너뜀 | 약관을 읽어보고 직접 캡처 |
| `unknown` | 약관 링크를 못 찾아 건너뜀 | 약관을 직접 읽고 문제없으면 `terms`를 `ok`로 지정 |
| `robots` | robots.txt가 막고 있어 건너뜀 | 수집하지 않기 |
| `blocked` | 봇 차단 화면이 떠서 건너뜀 | 직접 캡처 |
| `skip` | 화면을 찾지 못함 | `urls`로 지정 |
| `fail` | 오류 | 다시 실행 |
